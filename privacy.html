Privacy Policy

Last updated: November 20, 2026

This Privacy Policy describes how rclone personal (“the application”) accesses and handles data from Google Drive.

Who uses the application

The application is a personal, non-commercial tool used exclusively by its owner. It has no other users and is not offered to the public.

How the application works

The application accesses Google Drive only through rclone, an open-source command-line program that runs locally on the owner’s own devices. There is no server operated by the application: no data is sent to, received by or stored on any server other than Google’s own services. OAuth tokens are stored locally in the rclone configuration on the owner’s devices.

Data accessed

The application accesses the files and file metadata (such as names, sizes and modification dates) in the owner’s Google Drive, solely for the purpose of synchronizing the owner’s own files between the owner’s devices and Google Drive.

How data is used and shared

  • Data is not collected by the application or its developer.
  • Data is not sold, transferred or shared with any third party.
  • Data is not used for advertising, profiling or analytics.
  • Data is not used to develop, improve or train generalized or non-personalized artificial intelligence or machine learning models.

Google API Services User Data Policy

The application’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Cookies and tracking

This website and the application do not use cookies, analytics or any tracking technology.

Revoking access

Access granted to the application can be revoked at any time from your Google Account permissions page: https://myaccount.google.com/permissions. Deleting the rclone configuration on a device also removes the locally stored tokens.

Changes to this policy

If this policy changes, the updated version will be published on this page with a new “Last updated” date.
